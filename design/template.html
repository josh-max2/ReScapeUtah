IMPLEMENTATION RULES

  1. Field fills the window. No app bars; HUD floats as panels with 14px margins.
  2. Terrain pre-rendered once to an offscreen canvas: verge, path + carved edges, noise, treeline, rampart.
  3. Kill stains are persistent: stamp on a dedicated offscreen canvas at death position; never cleared during a run.
  4. Horde mass = two-tone pixel rects (dark outline pass + color pass, integer coords) — measured 6x faster than sprite blits at 20k. Big units (brute/titan) use round glow sprites.
  5. Fire renders additively ('lighter'): radial glow sprites at muzzles/impacts; smoke = gray alpha circles.
  6. Cyan is interaction-only: selected slot, ghost cell, selected range ring. Never decoration.
  7. Ranges only in build phase (dashed, white 22%); selected/ghost in cyan.
  8. Type: Bahnschrift, tabular numerals; labels letter-spaced uppercase; no emoji, no glow text.
  9. Vignette 34% warm-dark at edges, painted last over the field.
