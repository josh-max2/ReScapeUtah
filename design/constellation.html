ZOOM 1

THE CONSTELLATION

Four levels · 11 towers + the manual gun · 238 nodes
COMMAND at the centre. Every weapon is its own tree orbiting it, and every branch of that tree is itself a cluster — the branch node in the middle with its own upgrades ringed around it. Four levels deep, and the shape repeats at every level, so learning one tower teaches you all eleven.
ZOOM 2

AUTOCANNON

One tower, all 19 nodes · this is what a cluster looks like up close
The tower core, three branch nodes, and five upgrades ringed around each branch. Every ring is about its own branch: OUTPUT rings are power, REACH rings are coverage, IDENTITY rings all attack the same weakness — the Autocannon bounces off armour, so its identity ring is the answer to that.
ZOOM 2

CRYO SPRAYER

Same skeleton, completely different identity ring
Identical shape, and that is the point — but the Cryo's problem is that it barely damages anything, so its OUTPUT ring turns the freeze itself into damage and its IDENTITY ring is about the field it leaves behind rather than the car it hit.
ZOOM 2

MANUAL GUN

The weapon you aim · four fire modes · one shared heat bar
Not a tower — this is the gun the player holds, and the only cluster with four branches instead of three. It is a machine gun by default; the other three are fire modes you unlock and switch between. Heat is shared across all four, so switching modes is a real decision and holding any of them down has a cost. This mechanic does not exist in the sim yet — today the only active ability is the Q-strike, so this is new work, not an upgrade to something shipped.
EVERY NODE

EVERY TREE

11 towers + the manual gun · 185 upgrades · gold = capstone
Each tower's three rings, filled in. The first two rings mean the same thing on every weapon; the third is bespoke — it always attacks that weapon's own stated weakness, which is why the Autocannon's ring is about armour and the Rocket's is about wasted shots.
